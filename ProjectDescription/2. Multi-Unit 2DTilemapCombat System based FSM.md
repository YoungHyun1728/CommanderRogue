# FSM을 이용한 2D 타일맵 다중 전투

이 문서에서는 1번 문서에서 소개한 내용 중 전투 / 보스 노드에서 진행되는 전투 중 실행되는 동작들을 설명합니다.

- UnitFSM 설명
- 스킬 시스템

## 관련클래스

<img width="1131" height="739" alt="image" src="https://github.com/user-attachments/assets/d2a0ce22-fcc6-44b6-870f-221d868f931a" />

- UnitFSM: 전투 상태 머신입니다. Ready/Idle/Move/Attack/Faint/Stun 전이, 타겟 탐색, 공격 루프, 애니메이션 이벤트 기반 실제 공격 실행(ExecuteAttackFromAnimationEvent)을 담당합니다.
- UnitGridAgent: 타일 이동 의사결정 담당입니다. TryBuildIntent로 이동 의도 생성, A* 경로 선택/재계산 안정화, CommitMove로 실제 1칸 보간 이동을 수행합니다.
- BattleMovementSystem: 틱 기반 이동 관리자입니다. 모든 에이전트 intent 수집, 목적지 충돌 해결(우선순위/민첩도), 타일 점유 동시 반영 후 CommitMove 호출합니다.
- TileMapManager: 타일 상태의 단일 소스입니다. 걷기 가능 여부, 점유/해제, 강제 동기화, 월드↔타일 변환, 스폰 타일 탐색을 관리합니다.
- AStarPathfinder: 경로 탐색 유틸입니다. 점유/장애물 고려한 Manhattan 기반 A*로 경로를 계산합니다.
- UnitSkillSystem: 스킬 실행을 담당합니다. 풀마나 액티브(TryCastFullManaSkill), 패시브 트리거(OnBasicAttackHit, OnTakeDamage), 쿨다운, 강화평타 상태를 관리합니다.
- UnitStatusEffectController: 상태이상/버프 수명 관리자입니다. 독/이속저하/공속저하/피해증폭, 쉴드, 무적, 전투당 1회 부활, Ready 시 풀힐 같은 지속효과를 처리합니다.
- ProjectilePoolManager: 투사체 풀 매니저입니다. 타입별 프리팹을 미리 생성하고 Get/Release로 재사용합니다.
- Projectile: 실제 투사체 동작 담당입니다. 기본공격/스킬 투사체 초기화, 이동, 충돌 시 피해/스킬효과 적용, VFX 재생, 풀 반환을 처리합니다.
- Unit: 스탯/장비/레벨/피해 계산의 본체입니다. 공격력/공속/치명타 계산, 회복/포션/장비 적용을 담당합니다.

## 작동 흐름

1. 전투 노드 진입 시 적과 아군 모두 `Ready` 상태입니다.
2. `Ready`상태에선 아군 유닛을 드래그로 이동 가능합니다.
3. 배치가 끝나면 전투시작 버튼을 누르면 아군 유닛의 배치가 저장되고 모든 유닛이 `Idle`로 전이 됩니다.
4. `Idle` 상태에서는 가장 가까운 적을 타겟으로 지정하고 타겟이 정해지면 `Move`로 전이됩니다.
5. `Move`에선 타겟을 공격할 수 있을 때 까지 접근합니다. 타겟이 유닛의 공격범위에 들어오면 `Attack`로 전이합니다.
6. `Attack`에서는 적을 반복해서 공격합니다. 마나가 가득차면 `스킬`을 사용합니다. 타겟이 쓰러지거나 범위 안에 없다면 `Idle`로 전이됩니다.
7. 전투가 종료전까진 3~6을 반복하다가 전투 종료시 저장되었던 위치로 돌아가면서 `Ready`로 강제 전이됩니다.

## 작동 세부 설명

### 1. UnitFSM 설명

#### 상태 설명
| 상태 | 역할 | 진입 조건 | 종료 조건 |
|---|---|---|---|
| `Ready` | 전투 전 배치 / 배치 저장 | 전투 노드 진입 / 전투 종료 / 유닛 생성 | 전투 시작 -> `Idle`로 전이 |
| `Idle` | 타겟 설정 | 전투 시작 | 타겟 설정 완료 ( 공격 범위 체크 후 `Move` / `Attack` 로 전이) |
| `Move` | 타겟을 향해 이동 | 타겟 설정 (범위 내 타겟 없음) | 이동 완료(타겟 공격가능 위치까지 이동) -> `Attack`으로 전이 <br>타겟이 사라짐 -> `idle` 로 전이|
| `Attack` | 기본공격/스킬 실행 | 타겟 설절 (범위 내 타겟 있음) | 공격범위 내 타겟 없음 -> `Idle`로 전이 |
| `Stun` | 행동 불가 상태 | 스턴 효과 적용 | 스턴 시간 종료시 -> `idle`로 전이 |
| `Faint` | 전투 이탈 상태 | HP 0 이하 | Faint 상태 회복 아이템으로 회복 -> `Ready`로 전이 |

---

#### 1) Ready - 배치 / 포메이션 저장을 하는 상태

우선 전투 노드에 들어 가면 `RunManager`가 AllUnitsReady()를 호출해 모든 유닛의 fsm 상태를 Ready로 고정합니다.

Ready 상태에선 유닛들은 자리에 가만히 있는데, 이때 아군 유닛오브젝트의 `DraggableUnit`클래스가 드래그로 유닛배치를 변경할 수 있게 해줍니다. 드래그로 유닛을 움직이기 위한 클래스이므로 IBeginDragHandler, IDragHandler, IEndDragHandler 를 이용해 구현했습니다.
OnBeginDrag()에서 CanDrag()로 조건을 검사 합니다. 이때 조건 중 하나가 Unitfsm의 CurrentState가 Ready가 아니라면 return합니다.

배치를 마치고 전투시작 버튼을 누르면 `RunManager.SavePlayerFormation()` 가 호출 되어서 현재 위치를 저장 후 전투 시작을 위해 모든 Unit을 Idle로 전이 시킵니다. 

`SavePlayerFormation()`는 fsm의 고유 ID와 현재 좌표를 RunManager에 선언된 Dictionary<int, Vector2Int>에 저장합니다.

#### 2) Idle - 전투 시작을 위한 상태 / 타겟 설정을 한 후 Move나 Attack으로 전이 

Idle 상태에 돌입하면 바로 `targetEnemy`를 탐색합니다. `FindClosestEnemy()`함수가 `tileMapManager` 매니저의 아군, 적군 리스트를 순회에서 서로 가장 가까운 적을 `targetenemy`로 지정합니다.

그 후 `CheckAttackRange()`를 호출해 자신의 공격범위 내에 타겟이 있는지 확인합니다.

공격범위 내에 있다면 Attack으로 전이하고, 그보다 멀리 있다면 이동을 위해 Move로 전이하게 됩니다.

#### 3) Move - Attack을 위해 이동중인 상태 / MoveItent 제출

Move 상태에서는 `UnitFsm`이 실제로 이동을 동작하지 않고 `UnitGridAgent`에 타겟을 동기화 해주는 역할만 합니다. 

`BattleMovementSystem`가 틱 마다 `UnitGridAgent.TryBuildIntent()`를 호출해서 타일맵위의 모든 캐릭터들의

`MoveIntent : ( 현재위치, 목적지, 우선도 등이 저장되는 구조체 ) ` 를 수집합니다. 

같은 목적지로 충돌하게 되면 우선도를 이용해 `BattleMovementSystem`가 이동을 반려합니다.

틱의 마지막에 `CommitMove()`를 호출해 모든 캐릭터를 이동시킵니다.

#### 4) Attack - 타겟이 쓰러질때까지 공격하는 상태

Attack 상태가 되면 곧 바로 타겟을 공격하기 위해 `AttackCoroutine` 을 실행합니다.

`AttackCoroutine`
- 자신의 체력이 0이하면 Faint로 전이
- `CheckAttackRange()` 를 호출해 타겟이 범위 내에 없다면 Move로 전이
- 타겟이 쓰러지면 가까운 적을 재탐색, 없으면 Idle 로 전이

이 3가지를 거친 후 공격을 실행합니다. 먼저 공격 애니메이션이 실행되고 마지막 프레임에 애니메이션이벤트를 이용해 `ExecuteAttackFromAnimationEvent()`가 호출되게해서

이 시점에 공격이 실행되고, 마나를 확인해 가득차있으면 `스킬`을 사용하게 합니다.

해당 함수의 호출을 먼저 대기하고, 그 후 캐릭터의 공격딜레이 만큼 대기한 다음 재시작하게 합니다.

<img width="748" height="98" alt="image" src="https://github.com/user-attachments/assets/851500ac-6ae9-4f5f-904c-18d800702429" />

근거리 유닛의 경우 즉시 `Unit.DealDamage()` -> `ReceiveDamageWithResult()` 순서로 피해를 적용합니다.

원거리 유닛의 기본공격은 `ProjectilePoolManager` + `Projectile`로 투사체를 생성합니다.

`ProjectilePoolManager` 
- 시작 시 타입별 `initialSize`만큼 투사체를 미리 생성(풀링)
- 발사 시 풀에서 투사체를 꺼내 활성화(`Get`)
- 풀이 비어 있으면 1개 추가 생성 후 반환
- 사용 종료 시 비활성화 후 큐에 반납(`Release`)

`Projectile`
- `Init(shooter, target)`으로 발사자/타겟/속도/수명을 초기화
- 수명 만료 또는 타겟 소실 시 `Despawn()`으로 반납
- `OnTriggerEnter2D`에서 타겟과 충돌하면 `shooter.PerformAttack(target)` 실행합니다.
- 내부적으로 `Unit.DealDamage()` -> `ReceiveDamageWithResult()` 순서로 피해를 적용하고, 투사체를 반납합니다

정확한 순서는 `Get` -> `Init(shooter, target)` -> 충돌 / 수명만료 -> `Despawn()` -> `Release` 순으로 작동합니다.

#### 5) Stun - 기능정지 상태 / 스킬, 이벤트패널티 효과에 의해 정지

다른 상태이상과 다르게 Stun은 캐릭터의 애니메이션을 적용시키기 위해 FSM의 상태로 넣었습니다.

스킬이나 이벤트 패널티 효과에 의해 기절요청이 들어오면 `ApplyStun(duration)`을 호출합니다.

`ApplyStun(duration)`이 호출되면 `StunRoutine`이 시작되어 duration동안 대기한뒤에 ChangeState(UnitState.Idle)로 전투에 복귀합니다.

#### 6) Faint - 체력이 0 이하가 되어 이탈한 상태

전투 중에 캐릭터의 체력이 0이 되면 Faint 상태로 전이됩니다.

Faint 상태에선 곧 바로 `FaintRoutine`이 실행되며 쓰러지는 애니메이션을 실행합니다.

애니메이션이 종료되면 `tileMapManager.ReleaseUnitAll(unitId)` 를 통해 다른 캐릭터들의 이동을 위해 타일점유를 제거합니다. 

적 유닛이라면 `RunManager.OnEnemyDefeated` 함수를 통해 적레벨에 해당하는 골드와 경험치를 계산 후 삭제합니다.

아군 유닛이라면 gameObject.SetActive(false)로 비활성 상태로 만듭니다.

마지막으로 `CheckEndBattle()` 함수를 호출하여 적유닛, 아군유닛 중 한쪽이 0인지 확인해 승패를 정합니다.

상태를 `Ready`로 변경합니다.

### 2. 스킬시스템

앞서 `Attack` 상태에서 마나가 가득찬 상태에서 공격 시 스킬을 사용한다고 설명을 했습니다.

스킬은 마나가 가득찬 상태에서 사용되는 FullManaSkill 과 공격시 / 피격시 에 정해진 확률로 발동하는 PassiveSkill로 나누어 집니다.

스킬시스템을 구성하는 요소로는 
- SkillDefinition : ScriptableObject로 구현되어 스킬 설계도 역할을 합니다. 스킬이름, 발동조건, 효과 등을 저장하는 데이터입니다.
- SkillEffectDefinition : 공통 발동 규칙인 Execute만 선언되어있고 SE_Heal, SE_Addshield 등 자식클래스들이 내용을 가지고 있습니다. 
- UnitSkillSystem : 유닛의 스킬관리자입니다. 유닛오브젝트에 붙어 유닛이 가진 스킬을 관리합니다. ( 보유한 스킬 / 패시브 트리거 )
- SkillContext : 스킬이 발동될때 넘겨주는 상황 묶음입니다. 시전자, 목표유닛, 피해량 등 스킬 발동에 필요한 내용등을 한번에 전달합니다.
- UnitStatusEffectController : 상태 보관소 입니다. 독, 둔화, 화상 등 여러 효과들의 적용 / 해제 / 지속시간 등을 관리합니다.

SkillName, Icon, Description 은 게임 내에 직접 UI로 나타나는 부분이고 

Effects List가 SkillEffectDefinition으로 구현된 스킬 효과들입니다.
위 스킬에 사용된 효과들은 위에서 부터 순서대로

- Element 0 : 자신의 점유한 타일에 Vfx를 생성 (SE_VfxOnCasterTile)
- Element 1 : 가장먼 거리에 있는 적의 인접타일로 순간이동 (SE_TeleportAdjacentToBacklineEnemy)
- Element 2 : n번 MainStat에 비례해 기본공격강화 (SE_GrantEnhancedAttacks_MainStat)
- Element 3 : 버프 (SE_ApplyBuff)

이런 식으로 스킬효과들을 조립해서 스킬을 구성합니다.
