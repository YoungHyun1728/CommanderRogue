# FSM을 이용한 2D 타일맵 다중 전투

이 문서에서는 1번 문서에서 소개한 내용 중 전투 / 보스 노드에서 진행되는 전투 중 동작들을 설명합니다.

- UnitFSM 설명
- 스킬 시스템 설명
- 상태이상 ( 스킬 / 바이옴 )

## 작동 흐름

1. 전투 노드 진입 시 적과 아군 모두 `Ready` 상태입니다.
2. `Ready`상태에선 아군 유닛을 드래그로 이동 가능합니다.
3. 배치가 끝나면 전투시작 버튼을 눌러 모든 유닛이 `Idle`로 전이 됩니다.
4. `Idle` 상태에서는 가장 가까운 적을 타겟으로 지정하고 타겟이 정해지면 `Move`로 전이됩니다.
5. `Move`에선 타겟을 공격할 수 있을 때 까지 접근합니다. 타겟이 유닛의 공격범위에 들어오면 `Attack`로 전이합니다.
6. `Attack`에서는 적을 반복해서 공격합니다. 마나가 가득차면 `스킬`을 사용합니다. 타겟이 쓰러지거나 범위 밖으로

#### 상태 설명

| 상태 | 역할 | 진입 조건 | 종료 조건 |
|---|---|---|---|
| `Ready` | 전투 시작 전 초기화 상태 | 전투 노트 진입 / 전투 종료 / 유닛 생성 | 전투 시작 |
| `Idle` | 타겟 설정 | 전투 시작 | 타겟 설정 완료 |
| `Move` | 타겟을 향해 이동 | 이동 명령 확정 | 이동 완료(타겟 공격가능 위치까지 이동) |
| `Attack` | 기본공격/스킬 실행 | 공격 명령 확정 | 공격범위 내 타겟 없음 |
| `Stun` | 행동 불가 상태 | 스턴 효과 적용 | 스턴 시간 종료시 |
| `Faint` | 전투 이탈 상태 | HP 0 이하 | Faint 상태 회복 아이템으로 회복 |

#### 전이 조건

1. `Ready -> Idle`  
   전투 초기화(스폰, 턴큐, UI) 완료 시.

2. `Idle -> Move`  
   현재 턴 유닛이 이동 명령을 선택하고, 유효 타일이 있을 때.

3. `Idle -> Attack`  
   현재 턴 유닛이 즉시 공격(또는 이동 없는 스킬)을 선택할 때.

4. `Move -> Attack`  
   이동 후 공격 가능한 규칙일 때, 공격 명령이 이어서 확정될 때.

5. `Move -> Idle`  
   이동만 수행하고 턴 행동이 종료될 때.

6. `Attack -> Idle`  
   공격/스킬 실행, 피해/효과 적용, 쿨다운 반영까지 완료될 때.

7. `Any -> Stun`  
   스턴 부여 효과가 적중했을 때.

8. `Stun -> Idle`  
   스턴 지속 턴이 끝났거나 해제되었을 때.

9. `Any -> Faint`  
   HP 0 이하 또는 전투 불능 조건 충족 시.

10. `Faint -> (없음)`  
    전투 중 복귀 없음. 전투 종료 정산 대상만 유지.
